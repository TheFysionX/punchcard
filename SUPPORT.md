# Support

For usage questions and reproducible bugs, open a GitHub issue and include:

- Punchcard version (`punchcard status`);
- Node.js and operating-system versions;
- whether Discord reports connected;
- the expected and observed agent counts; and
- sanitized JSON from `punchcard status --json`, when relevant.

Do not upload Claude/Codex transcript files, prompts, source code, credentials, or npm debug logs that may contain private paths.

Use [private vulnerability reporting](https://github.com/TheFysionX/punchcard/security/advisories/new) for security problems rather than a public issue.
